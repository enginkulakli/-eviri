# PS5 Altyazı TV (Tizen)

Bu prototip Samsung TVWindow API ile HDMI kaynağını Tizen uygulamasının MAIN penceresinde gösterir. HTML altyazı katmanı HDMI görüntüsünün üzerinde kalır.

## Kullanım
1. TV uygulamasını aç.
2. PS5'in HDMI girişini seç ve HDMI görüntüsünü göster düğmesine bas.
3. Tablet uygulamasında ekran yakalamayı başlat; sonra Chiaki'ye geçip PS5 Remote Play görüntüsünü aç.
4. TV'de tabletin IP adresini girip Tablete bağlan düğmesine bas.

Bu ilk prototiptir. Tizen 4.0 / UE65NU7100 üzerinde gerçek cihaz testi yapılmadan HDMI görüntüsü, ses ve HDR davranışı garanti edilemez.
